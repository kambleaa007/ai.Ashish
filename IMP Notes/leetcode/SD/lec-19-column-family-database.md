# Lecture 19: Column-Family Database [1]

## Overview
Analyzes wide-column databases like Apache Cassandra and Google Bigtable [1].

## Features
- **Column-Oriented Storage**: Storing data by column families rather than row tuples [1].
- **High Write Throughput**: Append-only SSTable structures for massive write workloads [1].
- **Analytical Optimization**: Fast aggregations over specific columns across billions of rows [1].

## Summary & Key Takeaways
Column-family DBs power time-series analysis, IoT metric ingestion, and large-scale data analytics [1].
