# Lecture 11: Database Partitioning vs. Sharding [1]

## Overview
Differentiates single-node database partitioning from multi-node distributed database sharding [1].

## Core Differences
- **Partitioning**: Logical separation on a single database server instance [1].
- **Sharding**: Physical horizontal distribution of data across multiple distinct server nodes [1].
- **Shard Keys**: Selecting optimal shard keys to prevent hot-spotting [1].

## Summary & Key Takeaways
Sharding provides horizontal write scale, whereas partitioning optimizes localized single-node execution [1].
