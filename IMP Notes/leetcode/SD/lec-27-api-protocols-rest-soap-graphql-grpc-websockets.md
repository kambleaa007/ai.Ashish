# Lecture 27: API Protocols - REST, SOAP, GraphQL, gRPC & WebSockets [1]

## Overview
Comprehensive breakdown of modern web API protocols and selection criteria [1].

## Protocols Overview
- **REST**: HTTP/JSON standard, stateless, resource-oriented [1].
- **SOAP**: XML protocol with strict security contracts (WSDL) [1].
- **GraphQL**: Query-based API eliminating over-fetching and under-fetching [1].
- **gRPC**: HTTP/2 Protocol Buffers for high-performance microservice RPC [1].
- **WebSockets**: Full-duplex bidirectional persistent TCP connections [1].

## Summary & Key Takeaways
Select protocols based on latency requirements, payload sizes, and connection statefulness [1].
