# Lecture 14: Horizontal vs. Vertical Scaling [1]

## Overview
Compares methods for increasing system capacity and resource limits [1].

## Comparison
- **Vertical Scaling (Scale-Up)**: Adding CPU, RAM, or NVMe storage to an existing server node. Simple, but hardware limits and single point of failure exist [1].
- **Horizontal Scaling (Scale-Out)**: Adding more machine nodes in parallel. Highly resilient, virtually unlimited scale, but increases distributed management complexity [1].

## Summary & Key Takeaways
Modern cloud-native systems prioritize horizontal scaling for elasticity and fault tolerance [1].
