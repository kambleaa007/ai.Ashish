# Lecture 21: Security Layers in System Design [1]

## Overview
Explores multi-tiered security defense frameworks across application tiers [1].

## Security Pillars
- **Network Layer**: Firewalls, VPC subnet isolation, WAF (Web Application Firewall) [1].
- **Transport Layer**: SSL/TLS encryption [1].
- **Application & Data Layer**: Authentication, authorization (RBAC), data encryption at rest & in transit [1].

## Summary & Key Takeaways
Defense-in-depth ensures that a breach at one layer is contained before compromising the entire system [1].
