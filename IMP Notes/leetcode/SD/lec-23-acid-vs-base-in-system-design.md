# Lecture 23: ACID vs. BASE in System Design [1]

## Overview
Contrasts relational transactional guarantees (ACID) with distributed eventual consistency models (BASE) [1].

## Definitions
- **ACID**: Atomicity, Consistency, Isolation, Durability (Relational DBs) [1].
- **BASE**: Basically Available, Soft-state, Eventual consistency (NoSQL / Distributed stores) [1].

## Summary & Key Takeaways
Use ACID for financial transactions; use BASE for social media feeds and distributed web scale [1].
