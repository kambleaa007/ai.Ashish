# Lecture 02: What Happens When You Open a Website or Mobile App? [1]

## Overview
Explores the complete life cycle of an HTTP/HTTPS client request from the moment a user enters a URL or opens a mobile application [1].

## Request Lifecycle Steps
1. **User Action & Browser Input**: URL parsing and protocol identification [1].
2. **DNS Resolution**: Domain name conversion to server IP addresses [1].
3. **TCP/TLS Handshake**: Establishing secure socket connections [1].
4. **HTTP Request Generation**: Headers, payloads, and routing [1].
5. **Server Processing & Response**: Backend execution, database query, and HTML/JSON payload delivery [1].

## Summary & Key Takeaways
Understanding request flow is essential for diagnosing latency and pinpointing bottlenecks in web architectures [1].
