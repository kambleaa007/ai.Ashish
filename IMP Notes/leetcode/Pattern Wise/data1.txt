## 1. Two Pointers

* 
* The Blueprint: Using two indices to iterate through a linear data structure simultaneously (usually moving toward each other or from a fixed distance).
* Triggers: Input is sorted, or you need to find pairs/triplets that meet a specific target constraint.
* Core Problems: Two Sum II, 3Sum, Container With Most Water, Valid Palindrome.
* 

## 2. Sliding Window

* 
* The Blueprint: Maintaining a subsegment (window) of data over an array or string that grows, shrinks, or slides based on conditions.
* Triggers: Problem asks for a contiguous subarray or substring and contains keywords like "longest", "shortest", or "exactly $K$ elements".
* Core Problems: Longest Substring Without Repeating Characters, Minimum Size Subarray Sum, Fruit Into Baskets.
* 

## 3. Fast & Slow Pointers (Tortoise & Hare)

* 
* The Blueprint: Using two pointers that move at different speeds (usually one moves 1 step while the other moves 2 steps).
* Triggers: Finding loops or cycles in a linked list, array transitions, or finding the exact middle of a list.
* Core Problems: Linked List Cycle, Happy Number, Middle of the Linked List.
* 

## 4. Merge Intervals

* 
* The Blueprint: Sorting intervals by their start times and resolving overlaps sequentially.
* Triggers: Input consists of ranges, times, schedules, or intervals that overlap or need insertion.
* Core Problems: Merge Intervals, Insert Interval, Meeting Rooms, Non-overlapping Intervals.
* 

## 5. Modified Binary Search

* 
* The Blueprint: Logarithmic search $O(\log n)$ using a divide-and-conquer approach on arrays that aren't perfectly standard.
* Triggers: Input is sorted (or partially sorted, rotated, or contains a distinct peak) and requires sub-linear runtime execution.
* Core Problems: Search in Rotated Sorted Array, Find Peak Element, First and Last Position of Element.
* 

## 6. Tree/Graph Breadth-First Search (BFS)

* 
* The Blueprint: Level-by-level traversal using a Queue data structure.
* Triggers: Finding the shortest path in an unweighted graph, level-order traversal, or minimum steps to reach a state.
* Core Problems: Binary Tree Level Order Traversal, Word Ladder, Rotting Oranges.
* 

## 7. Tree/Graph Depth-First Search (DFS)

* 
* The Blueprint: Deep exploration of a branch down to its leaves before backtracking, using recursion or a Stack.
* Triggers: Exploring all possible paths, checking connectivity, evaluating tree structures, or matrix grid traversals.
* Core Problems: Number of Islands, Path Sum, Clone Graph, Flood Fill.
* 

## 8. Topological Sort

* 
* The Blueprint: Ordering nodes in a Directed Acyclic Graph (DAG) such that if edge $(u, v)$ exists, $u$ comes before $v$. Often implemented with Kahn's Algorithm (indegree array).
* Triggers: Managing dependencies, prerequisites, or ordering tasks that rely on prior tasks.
* Core Problems: Course Schedule, Course Schedule II, Alien Dictionary.
* 

## 9. Trie (Prefix Tree)

* 
* The Blueprint: A specialized tree structure used to store a re-retrievable set of strings where nodes represent character prefixes.
* Triggers: Auto-complete systems, checking prefix existence, or performing intensive dictionary/string lookups.
* Core Problems: Implement Trie (Prefix Tree), Design Add and Search Words Data Structure, Word Search II.
* 

## 10. Union-Find (Disjoint Set Union - DSU)

* 
* The Blueprint: An efficient data structure to track partitioned groups and merge sets together using find and union functions.
* Triggers: Checking if two items are in the same network, counting dynamic connected components, or finding redundant connections in a graph.
* Core Problems: Number of Connected Components in an Undirected Graph, Redundant Connection, Accounts Merge.
* 

## 11. Dynamic Programming (DP)

* 
* The Blueprint: Breaking a large problem into overlapping subproblems, solving them once, and caching the results via Memoization (Top-Down) or Tabulation (Bottom-Up).
* Triggers: Looking for the "maximum", "minimum", "longest", or "total number of ways" to achieve something where past choices affect future ones.
* Core Problems: Climbing Stairs, Coin Change, Longest Increasing Subsequence, House Robber.
* 

## 12. Greedy Algorithms

* 
* The Blueprint: Making the locally optimal choice at each step with the hope that it leads to a globally optimal solution.
* Triggers: Optimizing a scenario where picking the immediate best option doesn't disrupt later choices (requires proving correctness).
* Core Problems: Jump Game, Gas Station, Assign Cookies.
* 

## 13. Backtracking

* 
* The Blueprint: A systematic brute-force search that builds a solution incrementally and drops candidates ("backtracks") as soon as they violate constraints.
* Triggers: Generating all permutations, combinations, subsets, or solving puzzles (like Sudoku/N-Queens).
* Core Problems: Subsets, Permutations, Combination Sum, Word Search.
* 

## 14. Bit Manipulation

* 
* The Blueprint: Using bitwise operators (AND, OR, XOR, NOT, bit shifts) to process numerical binary data instantly.
* Triggers: Comparing numbers without basic operators, checking parity, or keeping track of subsets using bitmasks.
* Core Problems: Single Number, Number of 1 Bits, Counting Bits, Reverse Bits.
* 

## 15. Top K Elements (Heaps)

* 
* The Blueprint: Utilizing a Min-Heap or Max-Heap to keep track of a rolling, sorted threshold of elements.
* Triggers: Asks for the K-th largest, smallest, closest, or most frequent elements without sorting the entire dataset.
* Core Problems: Kth Largest Element in an Array, Top K Frequent Elements, Find Median from Data Stream.
*

## How to Master These Effectively
Don't study randomly. Use the Vertical Deep Dive Strategy:

   1. Choose one single pattern (e.g., Sliding Window).
   2. Spend 3 to 5 days doing only that pattern.
   3. Solve 3 Easy, 5 Medium, and 1 Hard problem using that specific blueprint.
   4. Move to the next pattern only after you can write the base template from memory.
