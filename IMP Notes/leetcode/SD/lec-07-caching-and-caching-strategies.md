# Lecture 07: Caching & Caching Strategies [1]

## Overview
In-depth study of memory caching tiers, cache invalidation policies, and performance optimization [1].

## Caching Levels
- Client / Browser Cache
- CDN Cache
- Application / In-Memory Cache (Redis / Memcached)
- Database Query Cache

## Eviction Policies
- Least Recently Used (LRU)
- First In First Out (FIFO)
- Least Frequently Used (LFU)

## Summary & Key Takeaways
Caching accelerates data retrieval by orders of magnitude but requires robust invalidation strategies to avoid stale data [1].
