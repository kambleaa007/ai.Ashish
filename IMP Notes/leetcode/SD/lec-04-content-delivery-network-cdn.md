# Lecture 04: Content Delivery Network (CDN) [1]

## Overview
Covers edge caching, geographical asset distribution, and reducing latency for static media delivery [1].

## Core Concepts
- **Edge Servers / PoPs**: Point of Presence locations distributed globally close to end users [1].
- **Static vs Dynamic Content**: Caching images, videos, CSS/JS files vs passing dynamic API queries through [1].
- **Push vs Pull CDN Models**: Proactive asset distribution vs fetch-on-demand caching [1].

## Summary & Key Takeaways
CDNs drastically improve loading speeds, reduce origin server load, and lower bandwidth costs [1].
