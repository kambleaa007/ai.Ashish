# Lecture 15: Microservice Architecture [1]

## Overview
Examines decomposing monolithic applications into independent, domain-driven microservices [1].

## Key Characteristics
- **Independent Deployment**: Deploying services without rebuilding the entire monolith [1].
- **Decoupled Data Stores**: Each service owns its dedicated database [1].
- **Inter-service Communication**: REST, gRPC, or message queues [1].

## Summary & Key Takeaways
Microservices improve team velocity and domain isolation, but introduce distributed tracing and network complexity [1].
