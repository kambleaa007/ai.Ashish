# Lecture 06: SSL Certificates & HTTPS Security [1]

## Overview
Explains Transport Layer Security (TLS/SSL), digital certificates, public key cryptography, and secure web communications [1].

## Key Concepts
- **Asymmetric Encryption**: Public/private key pairs used during initial handshake negotiation [1].
- **Symmetric Encryption**: Fast session keys generated for bulk payload encryption [1].
- **Certificate Authorities (CA)**: Verifying domain ownership and cryptographically signing SSL certificates [1].

## Summary & Key Takeaways
HTTPS ensures confidentiality, integrity, and authenticity across all client-server communications [1].
