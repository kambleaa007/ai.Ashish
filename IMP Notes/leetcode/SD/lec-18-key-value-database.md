# Lecture 18: Key-Value Database [1]

## Overview
Explores Key-Value storage paradigms (Redis, DynamoDB, Memcached) [1].

## Features
- **O(1) Access**: Ultra-fast lookup by primary key [1].
- **Simple Data Model**: String keys mapped to arbitrary byte arrays, strings, or data structures [1].
- **In-Memory & Persistence**: Options for pure RAM or disk-backed persistence [1].

## Summary & Key Takeaways
Key-value stores are ideal for session management, caching, user state, and real-time leaderboards [1].
