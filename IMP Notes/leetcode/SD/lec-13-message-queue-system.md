# Lecture 13: Message Queue System [1]

## Overview
Covers asynchronous processing, message brokers (RabbitMQ, Kafka), producer-consumer patterns, and decoupling services [1].

## Core Concepts
- **Asynchronous Communication**: Decoupling time-sensitive client requests from background processing [1].
- **Buffering & Traffic Spikes**: Absorbing heavy load bursts without overwhelming downstream services [1].
- **Publish-Subscribe vs Point-to-Point**: Message delivery paradigms [1].

## Summary & Key Takeaways
Message queues build resilience and prevent cascading failures in high-traffic architectures [1].
