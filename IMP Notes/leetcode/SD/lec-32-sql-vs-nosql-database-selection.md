# Lecture 32: SQL vs. NoSQL Database Selection [1]

## Overview
Decision framework for choosing between Relational SQL and Non-Relational NoSQL databases [1].

## Selection Criteria
- **Structure**: Fixed relational schemas (SQL) vs flexible semi-structured models (NoSQL) [1].
- **ACID vs BASE**: Financial transactions (SQL) vs massive throughput feed data (NoSQL) [1].
- **Scaling**: Vertical/Replica scale (SQL) vs seamless horizontal node sharding (NoSQL) [1].

## Summary & Key Takeaways
Modern polyglot persistence architectures frequently combine SQL for transactional core data and NoSQL for specialized workloads [1].
