# Lecture 22: HLD vs. LLD in System Design [1]

## Overview
Formal comparison between High-Level Design (HLD) and Low-Level Design (LLD) [1].

## Key Differences
- **HLD**: Architecture diagrams, component selection (DB, Cache, Queue), network topology, non-functional requirements [1].
- **LLD**: Class diagrams, database ER schemas, code modularity, design patterns, exact API payloads [1].

## Summary & Key Takeaways
HLD sets system boundaries and hardware topology; LLD provides the blueprint for developer code execution [1].
