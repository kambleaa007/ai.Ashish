# Lecture 25: SDK (Software Development Kit) & API vs. SDK [1]

## Overview
Explains Software Development Kits (SDKs) and how they encapsulate APIs [1].

## Differences
- **API**: The interface contract and HTTP endpoint specification [1].
- **SDK**: A suite of tools, libraries, documentation, and code samples wrapping APIs for specific programming languages [1].

## Summary & Key Takeaways
SDKs accelerate developer adoption by providing language-native method wrappers around raw API endpoints [1].
