## 5. Distributed Tracing

### Request ID
- Created for every request.
- Unique within a service.

### Correlation ID
- Shared across multiple services.
- Tracks a transaction end-to-end.

### Implementation
- Async Local Storage.
- Middleware-based identifier generation.
- Automatic propagation through requests.

### Benefits
- Simpler debugging.
- Request flow visibility.
- Easier distributed system analysis.

## 12. Introduction to Agent Loop Engineering

### Core Concept
Autonomous agents operate through a continuous loop rather than a single request-response cycle.

### Four Core Phases

#### 1. Perceive
- Receive input.
- Collect context.
- Read state.

#### 2. Reason
- Evaluate information.
- Use memory.
- Decide next actions.

#### 3. Act
- Execute tools.
- Invoke APIs.
- Run workflows.

#### 4. Evaluate
- Review results.
- Check goal completion.
- Continue or stop.

### Important Design Considerations
- Token management.
- Reliable tool execution.
- Deterministic behaviour.
- Convergence limits.
- Controlled iterations.
