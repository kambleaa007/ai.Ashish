# Lecture 09: What Are APIs (Application Programming Interface) [1]

## Overview
Defines API contracts, endpoints, request methods, payload formats, and interface design principles [1].

## Key Concepts
- **Contract Definition**: Standardized communication between heterogeneous software components [1].
- **REST Principles**: Resources, HTTP verbs (GET, POST, PUT, DELETE), statelessness, and JSON formats [1].

## Summary & Key Takeaways
APIs enable modular software development, decoupling frontends from backends and facilitating third-party integrations [1].
