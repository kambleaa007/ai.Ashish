# Lecture 10: Database Partitioning [1]

## Overview
Focuses on dividing large database tables into smaller, more manageable subsets on a single database instance [1].

## Types of Partitioning
- **Horizontal Partitioning**: Splitting rows based on key ranges or hash functions [1].
- **Vertical Partitioning**: Splitting columns into separate logical tables based on access patterns [1].

## Summary & Key Takeaways
Partitioning improves query response times and indexing efficiency for multi-million row datasets [1].
