# Lecture 20: Graph Database [1]

## Overview
Covers graph-oriented database systems (Neo4j, AWS Neptune) designed for interconnected data [1].

## Structures
- **Nodes**: Entities (e.g., Users, Products) [1].
- **Edges**: Relationships (e.g., Follows, Purchased, Friends) with properties [1].
- **Index-Free Adjacency**: Traversing connections without expensive SQL JOINs [1].

## Summary & Key Takeaways
Graph databases are optimal for social networks, fraud detection networks, and recommendation engines [1].
