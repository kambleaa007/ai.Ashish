# Lecture 05: Forward Proxy vs. Reverse Proxy [1]

## Overview
Contrasts client-side proxy servers with server-side reverse proxy servers [1].

## Comparison Matrix
- **Forward Proxy**: Protects/anonymizes the client, controls outbound network access, caches client requests [1].
- **Reverse Proxy**: Protects server backend, handles SSL termination, load balancing, compression, and ingress security [1].

## Summary & Key Takeaways
Forward proxies shield clients; reverse proxies shield and organize backend services [1].
