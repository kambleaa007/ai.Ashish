# Lecture 03: Load Balancer in System Design [1]

## Overview
Detailed examination of Load Balancers, their placement in architecture, routing algorithms, and high-availability setups [1].

## Core Concepts
- **Traffic Distribution**: Spreading incoming network requests across multiple server pools to eliminate single points of failure [1].
- **Algorithms**: Round Robin, Least Connections, IP Hash, and Weighted Round Robin [1].
- **Layer 4 vs Layer 7 Load Balancing**: Transport-layer (TCP/UDP) routing versus Application-layer (HTTP/HTTPS) content-aware routing [1].

## Key Real-World Examples
- Managing traffic bursts during peak e-commerce sales or streaming events [1].

## Summary & Key Takeaways
Load balancing provides horizontal scalability and high availability by ensuring no single server is overwhelmed [1].
